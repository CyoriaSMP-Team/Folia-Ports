### Rules
- Prefer verified official Folia releases and retain original license/credits.
- For open-source upstreams, fork from official upstream, preserve attribution, port, test on Folia, and keep the plugin binary name where practical.
- For privately maintained Cyoria code, keep the source private unless the owner explicitly publishes it.
- When `folia-supported` is absent, do not flip the flag without auditing region/entity schedulers, other thread access and shared data.
- GitHub Actions builds development artifacts but does not deploy to the live server.
- Record failures even if the plugin advertises Folia support.
