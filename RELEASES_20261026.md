## Internal experimental build snapshots

Other CyoriaSMP deployed plugin variants are inventoried as **private per-plugin GitHub Releases**, not public downloads. Each private repository stores the exact deployed binary and SHA-256 with provenance and verification caveats; affected vendors may have redistribution restrictions or missing corresponding source patches.

Original plugin configurations, auth data, Minecraft world data and secrets are not included in GitHub release artifacts.

## Compatibility / support

Always use the individual repository release notes. Verify Folia target and dependencies, retain attribution and original license, back up server data, and validate real-player multi-region interactions before deployment.

This index is not a blanket claim that all 107 active plugins are Cyoria-authored Folia ports. The original 14-plugin port migration work is tracked separately from unchanged upstream plugins.
